Розрахунково-графічна робота №1
Дисципліна: Крос-платформене програмування
Виконав: Павлов Вячеслав
Група: КБ22

Опис проєкту
Даний репозиторій містить реалізацію РГР №2, присвячену розробці компонентної архітектури на базі JavaBeans та системі обробки великих обсягів даних у форматі XML. Проєкт демонструє застосування принципів модульного програмування, використання потокових парсерів для оптимізації пам'яті та створення інтерактивної візуалізації статистичних даних.

Основні можливості:
1.Обробка XML: реалізація гібридного підходу — швидке читання великих файлів (6 МБ+) за допомогою SAX та структурований запис даних через DOM.
2.JavaBeans: розробка автономних візуальних компонентів (Таблиця та Графік), що взаємодіють між собою через механізм PropertyChangeListener.
3.Аналітична фільтрація: можливість динамічного пошуку та побудови графіків популярності імен на основі відфільтрованих статистичних записів.
4.GUI: графічний інтерфейс на базі Swing, що включає адаптивні панелі розділення (JSplitPane) та фонову обробку даних через SwingWorker.
5.Візуалізація: побудова динамічних графіків за допомогою власного рендерингу на базі Graphics2D з автоматичним обчисленням масштабів та осей.

Структура репозиторію
1.src/ — вихідний код програми (моделі даних, Beans-компоненти, XML-обробники,приклади XML-файлів зі статистичними даними).
2..git/ — історія комітів (версіонування проєкту).
3.README.md — детальний опис проєкту та інструкції.
4..gitignore — конфігурація для ігнорування бінарних та системних файлів.

Інструкція з налаштування
1.Проєкт розроблений з використанням стандартних засобів Java SE (Standard Edition), що забезпечує високу портативність та крос-платформеність.

Зовнішні бібліотеки:
1.У даній версії проєкту використання сторонніх бібліотек (як JFreeChart чи JCM) було замінено на власну реалізацію компонентів та стандартні пакети javax.xml, що дозволило зменшити розмір фінального продукту та продемонструвати глибше володіння базовим API Java.

Як запустити:
1.Відкрийте проєкт у середовищі IntelliJ IDEA.
2.Переконайтеся, що у налаштуваннях проєкту встановлено JDK 8 або вище.
3.Запустіть головний клас програми: MainApp.java.
4.У вікні програми введіть ім'я для аналізу (наприклад, Chloe) та виберіть XML-файл для завантаження.
